# Polsek Kapuas Tengah — website

Static homepage (Beranda) for Polsek Kapuas Tengah, Polres Kapuas, Polda Kalimantan Tengah.

Open `index.html` in a browser; no build step. Images live in `assets/`.

## Still placeholder / to confirm with the client
- Hero and Instagram cover photos are dummy Polri photos (`assets/hero-*.jpg`).
- News photos are hot-linked from analisnews.co.id and may break if the site blocks hot-linking.
- Kapolsek welcome text, Bhabinkamtibmas per desa, DPO / orang hilang lists.
- Polsek phone, address and service hours come from public sources (Facebook page, generic Polri hours).
- EN / Dayak Ngaju toggle only switches state; translations not written yet.
- "Cek status pengaduan" validates input only; no backend yet.
